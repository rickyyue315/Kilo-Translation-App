# Kilo 即時語音翻譯器

一個基於 Web Speech API 和 OpenRouter 的即時語音翻譯網頁應用程式，支援多語言即時翻譯和語音合成。

## 功能特色

- 🎤 **即時語音辨識**：使用 Web Speech API 進行連續語音辨識
- ⌨️ **文字輸入翻譯**：支援鍵盤輸入文字進行翻譯
- 🌍 **多語言翻譯**：支援中文、英文、日文、韓文、法文、西班牙文
- 🔊 **語音合成**：翻譯結果自動朗讀，支援多語音選擇
- 🤖 **AI 翻譯**：使用 OpenRouter API 進行高品質翻譯
- 📱 **響應式設計**：適配桌面和行動裝置，優化觸控體驗
- 💾 **翻譯歷史**：自動保存翻譯記錄，最多保存 50 筆
- 🔄 **流式翻譯**：即時顯示翻譯過程
- 🎯 **多 AI 模型選擇**：支援精選 AI 模型，基於 OpenRouter 2025 推薦清單 + 自定義選項
- 🌐 **多介面語言**：支援繁體中文、簡體中文、英文、日文、韓文介面
- 👥 **雙人交流模式**：支援兩人輪流對話，自動切換語言方向
- 🔍 **英語參考翻譯**：雙方都非英語時自動顯示英語中間翻譯
- 🔒 **雙重 API 金鑰模式**：伺服器端 API 金鑰（推薦）或用戶自行輸入

## 快速開始

1. **下載應用程式**
   ```
   git clone https://github.com/your-repo/kilo-voice-translator.git
   cd kilo-voice-translator
   ```

2. **開啟應用程式**
   - 直接在瀏覽器中開啟 `index.html` 檔案
   - 或使用本地伺服器：
     ```bash
     # 使用 Python
     python -m http.server 8000
     
     # 使用 Node.js
     npx serve .
     
     # 使用 PHP
     php -S localhost:8000
     ```

3. **設定 API 金鑰**（可選）
   - **選項 1：使用伺服器端 API 金鑰（推薦）**
     - 無需自行設定，系統自動使用安全存儲的 API 金鑰
     - 適合一般用戶，提供最佳安全性
     - 僅支援免費模型選項
   - **選項 2：自行輸入 API 金鑰**
     - 前往 [OpenRouter.ai](https://openrouter.ai/) 註冊帳號
     - 獲取 API 金鑰並在應用程式中輸入
     - 適合高級用戶，可使用自己的 API 配額
     - 支援所有模型選項（頂級、高性價比、免費、自定義）

4. **開始使用**
   - 選擇介面語言
   - 選擇 API 金鑰來源（伺服器端或自行輸入）
   - 選擇翻譯模式（單人或雙人）
   - 選擇來源語言和目標語言
   - 選擇 AI 模型（根據品質、速度和成本需求）
   - 選擇輸入模式（語音或文字）
   - 點擊「開始錄音」或在文字框中輸入內容
   - 系統會自動翻譯並朗讀結果

## 使用說明

### 基本操作

1. **介面語言選擇**
   - 在頁面右上角選擇介面語言
   - 支援繁體中文、簡體中文、英文、日文、韓文
   - 設定會自動保存

2. **翻譯模式選擇**
   - **單人翻譯模式**：適合個人使用，三欄顯示
     - 原始語音：顯示輸入的內容
     - 英語參考：當來源和目標語言都非英語時顯示
     - 翻譯結果：顯示最終翻譯
   - **雙人交流模式**：適合兩人對話
     - 使用者 A：說第一種語言
     - 使用者 B：說第二種語言
     - 點擊「交換使用者」按鈕切換當前使用者
     - 當雙方都非英語時，自動顯示英語參考翻譯

3. **語言選擇**
   - 選擇來源語言（您說的語言）
   - 選擇目標語言（要翻譯成的語言）
   - 使用 ⇄ 按鈕快速交換語言

4. **AI 模型選擇**
   - 選擇適合的 AI 模型進行翻譯
   - 支援頂級、高性價比、免費和自定義模型
   - 參考 [OpenRouter 官方模型列表](https://openrouter.ai/models)

5. **輸入模式選擇**
   - **語音輸入模式**：點擊「開始錄音」開始語音辨識，點擊「停止錄音」結束錄音
   - **文字輸入模式**：在文字框中直接輸入要翻譯的內容，點擊「翻譯文字」進行翻譯
   - 使用 Ctrl+Enter 快速翻譯（文字輸入模式）

6. **翻譯控制**
   - 點擊「朗讀翻譯」聽取翻譯結果
   - 點擊「清除文字」清空文字輸入框（文字輸入模式）
   - 點擊「清除歷史」清除所有翻譯記錄

### 雙人交流模式使用指南

雙人模式專為兩人對話設計，特別適合跨語言交流場景：

1. **模式切換**
   - 選擇「雙人交流模式」
   - 系統會顯示三欄：使用者 A、英語參考、使用者 B

2. **使用者切換**
   - 點擊「交換使用者」按鈕切換當前使用者
   - 當前使用者的欄位會高亮顯示
   - 使用者 A 使用來源語言，使用者 B 使用目標語言

3. **翻譯流程**
   - 使用者 A 說話 → 系統翻譯成英語 → 翻譯成使用者 B 的語言
   - 交換使用者後，使用者 B 說話 → 系統翻譯成英語 → 翻譯成使用者 A 的語言
   - 如果其中一方是英語，則直接翻譯，不顯示英語參考

4. **適用場景**
   - 商務會議
   - 旅遊導覽
   - 教學場景
   - 醫療溝通
   - 任何需要雙向翻譯的場景

## API 金鑰管理

### 🔒 雙重 API 金鑰模式

本應用程式提供兩種 API 金鑰使用模式，滿足不同用戶的需求：

#### 1. 伺服器端 API 金鑰（推薦）

- **便利性**：無需註冊帳號或獲取 API 金鑰，即可立即使用
- **成本控制**：由管理員統一管理使用額度和成本
- **適合對象**：一般用戶、企業內部使用、教育機構
- **限制**：僅支援免費模型選項

#### 2. 用戶端 API 金鑰
- **靈活性**：用戶可使用自己的 OpenRouter API 金鑰
- **獨立性**：使用自己的 API 配額和計費
- **自定義**：可使用任何 OpenRouter 支援的模型
- **適合對象**：高級用戶、開發者、需要大量使用的用戶
- **優勢**：支援所有模型選項（頂級、高性價比、免費、自定義）

### API 金鑰設定

#### 選項 1：使用伺服器端 API 金鑰（預設）
1. 選擇「使用伺服器 API 金鑰（推薦）」選項
2. 系統會自動使用安全存儲的 API 金鑰
3. 僅顯示免費模型選項
4. 無需額外設定即可開始使用

#### 選項 2：自行輸入 API 金鑰
1. 選擇「自行輸入 API 金鑰」選項
2. 前往 [OpenRouter.ai](https://openrouter.ai/) 註冊帳號
3. 在控制台中獲取 API 金鑰
4. 將 API 金鑰輸入到應用程式中
5. 系統會安全地將金鑰存儲在瀏覽器本地
6. 可使用所有模型選項

### OpenRouter API 設定

1. **獲取 API 金鑰**
   - 訪問 [OpenRouter.ai](https://openrouter.ai/)
   - 註冊帳號並登入
   - 在控制台中獲取 API 金鑰

2. **查看推薦模型**
   - 前往 [OpenRouter 官方模型列表](https://openrouter.ai/models)
   - 查看最新的模型推薦和定價資訊

3. **設定請求參數**
   ```javascript
   const response = await fetch('https://openrouter.ai/api/v1/chat/completions', {
       method: 'POST',
       headers: {
           'Authorization': `Bearer ${apiKey}`,
           'Content-Type': 'application/json',
           'HTTP-Referer': window.location.origin,
           'X-Title': 'Kilo Translation App'
       },
       body: JSON.stringify({
           model: 'openai/gpt-4o',
           messages: [
               {
                   role: 'system',
                   content: '你是一個專業的翻譯助手...'
               },
               {
                   role: 'user',
                   content: text
               }
           ],
           stream: true,
           temperature: 0.3,
           max_tokens: 1000
       })
    });
    ```

## 故障排除

### 常見問題

1. **麥克風權限被拒絕**
   - 檢查瀏覽器設定中的麥克風權限
   - 確保沒有其他應用程式佔用麥克風
   - 重新整理頁面並再次請求權限

2. **語音辨識不準確**
   - 確保環境安靜，減少背景噪音
   - 調整麥克風距離和音量
   - 選擇正確的語言設定
   - 嘗試使用文字輸入模式

3. **API 翻譯失敗**
   - 檢查 API 金鑰是否正確
   - 確認網路連線穩定
   - 檢查 API 使用額度
   - 嘗試切換不同的 AI 模型
   - 檢查是否選擇了正確的 API 金鑰來源

4. **語音合成無法播放**
   - 檢查瀏覽器音量設定
   - 確認目標語言有可用的語音
   - 嘗試重新整理頁面
   - 檢查是否被其他應用程式佔用

5. **模型選擇問題**
   - 確認選擇的模型在 OpenRouter 上可用
   - 檢查模型是否支援您的目標語言
   - 參考官方模型列表確認最新狀態
   - 伺服器端模式僅支援免費模型

6. **雙人模式問題**
   - 確保正確切換使用者
   - 檢查語言設定是否正確
   - 確認英語參考是否應該顯示（雙方都非英語時）

### 錯誤代碼

- `no-speech`：未檢測到語音輸入
- `audio-capture`：無法存取麥克風
- `not-allowed`：麥克風權限被拒絕
- `network`：網路連線錯誤
- `401`：API 金鑰無效
- `429`：API 請求過於頻繁
